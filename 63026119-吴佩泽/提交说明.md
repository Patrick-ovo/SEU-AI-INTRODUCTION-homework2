## 2. 命题与数学证明

本题通常称为**欧几里得定理（素数无穷多）**。这里按正整数解释 n；不涉及实数或整数的其他范围。

任取自然数 n，令 N = n! + 1。因为 n! > 0，所以 N > 1，存在素数 p 使 p 整除 N。

假设 p ≤ n。由于 p 是素数，p > 0，因此 p 是阶乘 n! 中的一个因子，故 p 整除 n!。结合 p 整除 n! + 1，得到 p 整除二者之差 1。这与素数不能整除 1 矛盾。因此 p > n。

上述证明对所有自然数成立，包括 n = 0，因此也证明了题目要求的正整数情形。证明仅使用 N 有素因子这一事实，并不声称 N 本身一定为素数。

## 3. Lean 命题与证明对应

更强的自然数版本：

```lean
theorem exists_prime_gt (n : ℕ) :
    ∃ p : ℕ, Nat.Prime p ∧ n < p := by
  -- 完整证明见 Euclid.lean
```

题目要求的正整数版本：

```lean
theorem exists_prime_gt_pos (n : ℕ) (_hn : 0 < n) :
    ∃ p : ℕ, Nat.Prime p ∧ n < p := by
  exact exists_prime_gt n
```

`_hn` 表示 n 为正整数的假设。由于已经证明更强的自然数版本，这个假设不需要参与推导；结论与原题一致，没有增加额外条件。

关键步骤：

1. `Nat.factorial_pos n` 给出 n! > 0，`omega` 推出 n! + 1 ≠ 1。
2. `Nat.exists_prime_and_dvd` 取得 n! + 1 的素因子 p。
3. `by_contra` 假设 n < p 不成立，`omega` 推出 p ≤ n。
4. `Nat.dvd_factorial hp.pos hle` 推出 p 整除 n!。
5. `(Nat.dvd_add_iff_right hpfact).2 hpdvd` 推出 p 整除 1。
6. `hp.not_dvd_one hpone` 得到矛盾，完成证明。

以上片段用于解释，实际检查应使用 `Euclid.lean` 的完整内容。
